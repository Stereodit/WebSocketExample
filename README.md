# WS Рынок

Android-приложение на Jetpack Compose: живые котировки и лента сделок через публичный WebSocket Binance. Ключ API не нужен.

Поток: `wss://data-stream.binance.vision/ws`.

## Экраны

**Рынок.** Одно соединение подписывается на `miniTicker` шести пар: BTC, ETH, SOL, BNB, XRP и DOGE. На экране цена, изменение за 24 часа, объём, состояние сокета и короткий журнал handshake. Кнопка обрывает поток и поднимает его снова.

**Сделки.** Нажатие на пару открывает второе, независимое соединение и подписывается на `symbol@trade`. Зелёная строка — рыночная покупка (taker купил), красная — рыночная продажа. Вкладка «Журнал» показывает кадры этого сокета: `CONNECT`, `SUBSCRIBE`, ответ сервера, `PING` и `PONG`.

Системная кнопка «Назад» закрывает ленту и останавливает второе соединение. Соединение рынка при этом остаётся.

## Что делает клиент

Клиент в `websocket/ReconnectingWebSocket.kt` реализует [RFC 6455](https://datatracker.ietf.org/doc/html/rfc6455) поверх TLS, без сторонней WebSocket-библиотеки:

- HTTP Upgrade и проверка `Sec-WebSocket-Accept`;
- маскирование исходящих кадров;
- сборка фрагментированных сообщений;
- ответ `PONG` на `PING` сервера и свой keepalive раз в 20 секунд;
- подписка сообщением `SUBSCRIBE`;
- повторное подключение с паузой от 0,5 с до 15 с, если сеть или сервер оборвали поток.

Разбор JSON и кадров покрыт локальными тестами в `app/src/test`.

## Запуск

Нужны Android Studio, уже установленные JDK и Android SDK, и устройство или эмулятор с интернетом. Минимальная версия Android — 8.0 (API 26).

Откройте проект и запустите конфигурацию `app`. Котировки появляются сразу после старта.
